# Arley Bakery website

Single-page site for Arley Bakery (Pilsen, Chicago), built with Next.js, Tailwind CSS, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All text, hours, prices, phone, address and photo references live in `content/site.ts`.

## Checks

```bash
npm run lint
npm run build
npm run test:e2e
```
